# close-out

The finish-line ritual for a focus that is truly done: the Done call, the archive,
the milestone. Three verbs the project already knows, in the order accountability
wants them.

## When to run

- A focus's work is delivered and the Human Lead is ready to call it — and the
  close deserves the full ceremony (a release, a completed campaign, a shipped
  redesign). A modest focus may take `complete-focus` alone and skip the rest;
  this process is for closes that are milestones.

## The steps

1. **`complete-focus`** — the Human Lead's Done call: gate walk (build) or critique
   + judgement (goal); waivers on the record.
2. **`archive-focus`** — the finished subtree relocates; the working tree lightens.
3. **`save-point`** — seal the accumulator into the dated entry: the milestone's
   story is every ack since the last one, already written. (Requires all child
   tracks closed — merge or abandon stragglers before starting the ritual.)

## Done looks like

The stack has one fewer working row; the archive index has one more line; the
ledger has a sealed entry with pins and a fresh open `next`. Both repos clean.
